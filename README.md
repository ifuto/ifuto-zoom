# ifuto-zoom

Minecraft (Fabric / **1.21.11**) 用のシンプルで滑らかな **Zoom Mod** です。

<img src="logo.png" alt="Ifuto Zoom" width="220">

## 機能

- **デフォルトキーバインド: `C`**（設定から変更可能！）
- **押している間だけ拡大 / 押すたびに拡大・通常を切り替え** の 2 モードを Mod Menu の設定画面から変更可能！
  （デフォルトは **押している間だけ拡大**するタイプのやつ）
- `C` を押すと **3 倍** に拡大します（倍率も設定画面で変更可能）
- **スクロールで倍率を変更**
  - 拡大は実質無制限（安全上限 1000x）です。
  - 縮小は設定した **縮小の限度**（デフォルト 1.0x = 通常視野）まで縮小することができます。
  - 倍率は対数的に変化するので、どの倍率でも 1 ノッチの感覚が一定です。
- アニメーションもついているので、動画映えする！カーブと所要時間は設定可能です！
  - 最初は速く、だんだん遅くなる（イーズアウト）減速がはっきり分かるように作っています！
  - スクロール中は追従スムージング（既定 175ms、設定で変更可能）で、ノッチごとに止まらず一枚の滑らかな動きで拡大・縮小します
  - カーブの強さ（指数）もスライダーで自由に調整できるので、好みの「波」にカスタマイズできます
  - 拡大・戻りの時間は常に設定時間（デフォルト500ms）で一定です。たくさん拡大してから戻っても同じテンポで戻れます
- 拡大中は **マウス感度を自動で低下**します（オン/オフ・強さを設定可能）
- 拡大されるのはワールドの描画のみで、**手持ちアイテムは通常サイズのまま**なので、高倍率でも視界を塞ぎません
- 日本語・英語のローカライズ対応

## 設定（Mod Menu）

Mod Menu の一覧から `Ifuto Zoom` → `Config` を開くと、以下を変更できます。

| 項目 | 説明 | 既定値 |
| --- | --- | --- |
| ズーム方式 | 押している間 / 切り替え | 押している間 |
| 拡大倍率 | キーを押したときの倍率 | 3.0x |
| アニメーション | なし / リニア / 最初は速く、どんどん遅く / 同（強）/ 最初は遅く、どんどん速く / 両端なめらか | 最初は速く、どんどん遅く |
| アニメーション時間 | 0〜1500 ms（拡大開始・終了の所要時間） | 500 ms |
| スクロール滑らかさ | スクロール時の追従時間（0 で即時） | 175 ms |
| カーブの強さ | 速度カーブの指数（1〜5。大きいほど序盤が速く、終盤がゆったり） | 2.0 |
| 縮小の限度 | スクロールで縮小できる下限 | 1.00x |
| スクロール刻み | 1 ノッチあたりの倍率変化 | 15% |
| スクロールで倍率変更 | ズーム中のスクロールを倍率変更に使う | オン |
| 倍率を維持 | ズーム終了後も倍率を保持する | オフ |
| 感度を下げる / 感度の下げ幅 | 拡大中のマウス感度調整 | オン / 100% |

設定は `config/ifuto-zoom.json` に保存されます。Mod Menu が入っていなくても、この JSON を直接編集すれば設定できます。

## 必要環境

- Minecraft **1.21.11**
- Fabric Loader — 1.21.11 対応の **全バージョン**（0.16.0 以上ならそのまま動作します）
- [Fabric API](https://modrinth.com/mod/fabric-api)
- （任意）[Mod Menu](https://modrinth.com/mod/modmenu) **17.x** — GUI 設定画面用
