# KB Meter (ifuto-kb)

サーバー別ノックバック係数を実測するクライアント Mod。バニラ = 1.0 基準。

## 使い方

1. まずシングルプレイで MOB を殴る・殴られる（10 回程度で校正完了）
2. 鯖で 1 対 1 の素振り（殴り・被弾 各 10 回程度）
3. タイトル / ポーズ画面右上の KB ボタン → 鯖一覧 → 詳細で係数と JSON

## 仕組み

- 式計算はしない。シングル実測を基準表にして、鯖の実測を割って係数を出す
- 殴り：スイング + 相手の速度スパイク（減衰フィットで初速復元）
- 被弾：速度パケット + 体力減 + 攻撃者パケットの三点照合
- 要約は中央値（外れ値に強い）。弱ヒット疑いは主推定から除外
- 保護（ロビー等）は KB 自体が無いので noSpike として自動除外

## 除外理由

- noSpike：殴ったのに相手が動かない（保護・ミス）
- noDamage / nonMelee：ダメージなし・近接以外（矢・釣竿・爆発など）
- wrongDir：KB の向きが自分由来じゃない（第三者の攻撃）
- vehicle：どちらかが乗り物に乗っている（バニラは KB なし）
- noSource / unattributed：攻撃者が分からない
- immuneBaseline：完全耐性の基準セル

## KnockBackSync 導入鯖

対応。KB Sync は被害者のクライアント状態で KB を再計算するので、
クライアント観測の条件で割るこの Mod の値はそのまま成立する。
ping 欄と設置欄を見れば挙動の裏取りもできる。

## 制限

- 相手の KB 耐性はネザライト数 x 0.1 で推定（属性自体は鯖から見えない）
- プラグイン付与の耐性は見えない
- スイープ・サボテン等の間接 KB は対象外（直接ヒットのみ）
- 未校正セルは推定値（seedUsed）で補う。シングル校正を推奨
