# F3 Faker (ifuto-f3)

F3 デバッグ画面の文字・数値を全部詐称するクライアント Mod。
Mod Menu の設定画面で編集する。BetterF3 にも対応。

## できること

- FPS 詐称 3 モード: FIXED（固定）/ FOLLOW（本物に連動）/ RANGE（指定範囲をうろつく）
- 座標詐称 4 モード: OFF / OFFSET（ずらし）/ ANCHOR（基準点＋移動差分）/ FIXED（完全固定）
- スペック・メモリ・向き・バイオーム等の文字上書き
- 汎用ルール（正規表現）x4
- 診断画面（見つけた行の一覧・フック状態）

## 使い方

1. Mod Menu から「F3 Faker 設定」を開く
2. 座標の ANCHOR は「今いる場所を基準点に」で基準点を取る
3. 閉じると保存される

## 仕組み

- バニラ: `DebugHudLines` の add 系に書き換えをかける
- BetterF3: `DebugLine.value()` の値を id ごとに書き換える
- FPS: `getCurrentFps()` の返り値だけ詐称（フィールドは本物）
- 全部クライアント内・表示だけ。パケットは触らない

## 制限

- F3 のグラフ（チャート）は対象外
- バニラ行の形式が変わると外れることがある（診断画面で確認・報告を）
- ワールドのシードが必要なもの（スライムチャンク等）は上書き文字のみ

## テスト

`./gradlew -p ifuto-f3 testF3`（CI で毎回）
