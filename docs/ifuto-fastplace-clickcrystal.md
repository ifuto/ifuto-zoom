# ClickCrystal 設計メモ

対象: `ifuto-fastplace` 0.5.0 / Minecraft 1.21.11 (Fabric)

黒曜石（岩盤）を**左クリック**すると、ホットバーのエンドクリスタルへ数 ms で
持ち替え、**置く → 爆破する**を `clickCrystalIntervalMs` 間隔で連続実行する。

## 手順

1. 左クリックの瞬間、クロスヘアが黒曜石/岩盤（上が空気・`clickCrystalRange` 以内）を
   指していて、ホットバーにエンドクリスタルがあるか確認
2. あれば **武装**（同じ tick でスロットをクリスタルへ切り替える = 数 ms）
3. `clickCrystalIntervalMs` ごとに:
   - 近く（6 ブロック以内）のエンドクリスタルを**攻撃**して爆破
   - 黒曜石の上面に**設置**
4. `clickCrystalBurstMs` 経過 / クリスタル切れ / 距離が離れた / 画面を開いた で終了。
   終了時に `clickCrystalRestoreSlot` が ON なら元のスロットへ戻す

## 順番が大事

パケットは順序どおり届くので、**攻撃 → 設置**の順に送ればサーバーでは必ず
「爆破 → 設置」になる。クリスタルは空間を占有するので、逆順だと設置が失敗する。

## 設定

| 項目 | 既定 | 意味 |
| --- | --- | --- |
| 間隔 | 45 ms | 1 サイクルの間隔 |
| 連続時間 | 1200 ms | 1 クリックで撃ち続ける時間 |
| 届く距離 | 4.5 b | 対象として認識する距離 |
| 元のスロットに戻す | ON | 終了時の挙動 |

## 注意

- 爆風は自分にも当たる。**距離を取って撃つ**こと（この Mod は退避しない）。
- サーバー側で自動設置・連打が禁止されている場所では使わないこと。
- 置く/攻撃はバニラの相互作用 API を通すので、パケット偽装はしていない。
