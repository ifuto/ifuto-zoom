# ClickCrystal 設計メモ

対象: `ifuto-fastplace` 0.6.0 / Minecraft 1.21.11 (Fabric)

黒曜石（岩盤）を**左クリックして押している間だけ**、`置く → 殴る` を繰り返す。
**離した瞬間に止まる**。パケットは組み立てず、`interactBlock` / `attackEntity`
（バニラの左クリック・右クリックと同じ入口）と**実際の視点移動**だけで動かす。

## 1 サイクル

1. **向く**: 黒曜石の上面中心へ、毎フレーム少しずつ体の yaw/pitch を回す
   （`human/SmoothLook`。速度は残り角度 × ゲイン、上限は設定値）
2. **確かめる**: 毎フレーム `World#raycast` を引き直し、クロスヘアが**本当に**その
   黒曜石の**上面**に当たっているときだけ進む（`crosshairTarget` は 20Hz で古いので使わない）
3. **置く**: ホットバーのエンドクリスタルへ切り替え、その実ヒット結果で `interactBlock` +
   `swingHand`
4. **探す**: 置いた位置（上面の中心から 0.6 ブロック以内）にある `EndCrystalEntity` だけを対象にする
5. **殴る**: そのクリスタルへ実際に向き直し、
   - 目視できる（`PlayerEntity#canSee`）
   - 視線がブロックや他のエンティティに遮られていない（`AimAssistModule.clearLine`）
   - 目から 3.0 ブロック以内（バニラの攻撃リーチ）
   の 3 つを満たしたときだけ `attackEntity` + `swingHand`
6. `clickCrystalIntervalMs` 待って 1 に戻る（押しっぱなしなら繰り返す）

## やらないこと（重要）

- **見えないクリスタルを殴らない**。「近くにあるクリスタルを片っ端から攻撃」はしない
  （以前の実装は半径 6 ブロックのクリスタルを無条件で殴っていた。壁越しでも当たっていた）
- **届かない距離で殴らない**（3.0 固定。設定の「狙う距離」は置く側に効く）
- **置けなかったのに殴らない**（クリスタルが来なければ 500ms で諦める）
- **パケットを自前で作らない**。キー表示 Mod に「押した」と見せる細工もしない

## 押しっぱなしの扱い

- `attackKey` の**物理的な押下**（`VirtualKeys.physical`）だけを見る
- 離したら即座に止まり、`clickCrystalRestoreSlot` が ON なら元のスロットへ戻す
- 画面を開いた / モジュール OFF / 死亡・スペクテーター でも同じ後始末

## 設定

| 項目 | 既定 | 意味 |
| --- | --- | --- |
| 連打の間隔 | 45 ms | 1 サイクルの間隔（20〜300） |
| 振り向く速さ | 420 °/s | 視点を回す上限速度（60〜900） |
| 狙う距離 | 4.5 b | 置く対象として認識する距離（1〜6、実際の設置は 4.5 で頭打ち） |
| 元のスロットに戻す | ON | 終了時の挙動 |

## 注意

- 爆風は自分にも当たる。**距離を取って撃つ**こと（この Mod は退避しない）。
- 左クリックを押している間はバニラの攻撃もそのまま走る（黒曜石を掘り始めることがある）。
  これは「実際に操作している」ことの副作用で、意図的に止めてはいない。
- サーバー側で自動設置・連打が禁止されている場所では使わないこと。
