# Auto Safe Anchor 設計メモ

対象: `ifuto-fastplace` 0.6.0 / Minecraft 1.21.11 (Fabric)

自分が**リスポーンアンカーを置いた瞬間**に、手前に 1 ブロック置ける空間があるときだけ
「安全なアンカー」を自動で組む。

## 手順（と、その理由）

1. **グロウストーンを持ち、アンカーを 1 回だけチャージ**
   アンカーは 1 チャージで起爆できる。2 回以上チャージすると威力が上がるが、
   ここでは「1 回だけ」が要件。
2. **アンカーの手前の地面へ視点を移し、グロウストーンを置く**
   手前（自分側）の 1 ブロックに壁を作ることで、爆風のレイが自分に届かなくなる。
   **アンカーを向いたまま置くと 2 回目のチャージになる**ので、必ず
   「手前の空間の下にある地面ブロックの上面」を狙う。
3. **アンカーを持って、壁ごしに見えるアンカーの面を右クリック（起爆）**

## 実装上のポイント

- 各段階で **毎フレーム `World#raycast`** を引き、クロスヘアが
  「狙うべきブロック」に当たっている**ときだけ**右クリックする。
  当たっていなければ回転を続けるだけ（押さない）。
- 回転は `human/SmoothLook`（フレーム単位・上限速度つき）で、体の yaw/pitch を実際に動かす。
  パケットの偽装はしない。
- スロット変更（グロウストーン / アンカー）と右クリックの間にも待ち時間を置く
  （スロットのパケットがサーバーに届いてから操作する）。
- チャージ確認はブロック状態の `charges` プロパティを読む（読めない環境では
  「1 回押した」ことを信じて進む）。

## 失敗したときの扱い（安全側）

| 状況 | 動作 |
| --- | --- |
| 手前に空間が無い | 何もしない |
| 手前の下に地面が無い | 何もしない（地面を向いて置けない） |
| グロウストーン / アンカーが無い | 何もしない |
| アンカーを向けない（1.4 秒） | 何もしない |
| チャージが入らない（450ms） | 壁も作らず、起爆もしない |
| 壁を置けない（500ms） | 起爆しない |
| アンカーが見えない（2.2 秒） | 起爆しない |

**勝手に爆発させない**のが既定。途中でやめたときは `safeAnchorRestoreSlot` が ON なら
元のスロットへ戻す。

## 設定

| 項目 | 既定 | 意味 |
| --- | --- | --- |
| 振り向く速さ | 400 °/s | 視点を回す上限速度（60〜900） |
| 操作どうしの間隔 | 70 ms | スロット変更 → 右クリック などの間（50〜400） |
| 元のスロットに戻す | ON | 終了時の挙動 |
