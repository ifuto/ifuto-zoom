# Ifuto SmoothHud

treegfx の SmoothHud（LGPL-3.0）の修正フォーク。選んだ枠を滑らかに動かす。

元 Mod は追いかけの計算に上限がなく、カクつき・切り替え時に枠が場外へ
飛び出すことがある。このフォークは追い越しを禁止し、枠の中に固定した。

- 元: https://modrinth.com/mod/smooth-hud（© treegfx、LGPL-3.0-or-later）
- 使い方は元と同じ（Mod Menu から速度を変えられる）
- 見本の数字キー切り替えは無い（1.21.11 の Yarn に名前が無いため。ホイールで試せる）
- 元の Mod とは一緒に入れない（枠の取り合いになるため）
