# FastPlace (ifuto-fastplace)

右クリック長押しで、ブロックの連続設置間隔を自由に変えられる Mod です（既定 55ms）。

ただし、機械のような一定間隔にはしません。**人間の連打のクセ**を統計モデルで再現しています。

## できること

- 設置間隔の変更（20〜500ms、既定 55ms）— Mod Menu の設定画面のスライダー
- 表示 CPS の ON/OFF（連打中だけ画面右上に小数1桁で出ます。決して整数になりません）

## 人間らしくする仕組み

- 間隔 = **時計成分 + 運動遅延の差分**（Wing–Kristofferson 1973）
- 時計成分は **ex-Gaussian**（正規 + 指数裾）— 反応時間研究の標準モデル。速いクリックより遅いクリックが出やすい
- 時計成分には**低周波のゆっくりしたドリフト**（1/f 的長距離相関の近似、Gilden et al. 1995）
- その偏りの**比率は固定しない**。sigma/tau 比がランダムウォーク → 標準偏差も毎回変わる
- **19 回は普通の乱数、20 回目だけ暗号学的乱数**（SecureRandom）でブレを入れる
- 毎回のクリックに**±2.5% の微小なブレ**
- **疲労**: クリックするたびに、残り容量のごく一部だけが積み上がる（漸近に近づくだけで、限度値にベタ張り付きしない）。
  元値にだけ **+25% の上限**がかかり、**Jitter はその上限を突破できる**。不便にならない範囲
- 連打をやめると、**時間とともに指数的に回復**する
- **2 秒ごとに Jitter の強さと外れ値率が動的に変化**する（どちらも微細で、プレイヤーには分からない）
- まれに**外れ値**（少し大きく遅れる hesitation）を打つ
- **CPS は毎 tick 細かく変動**し、小数1桁・整数にはならない

## 使い方

1. Mod Menu から「FastPlace 設定」を開く
2. 間隔はスライダーで変更。閉じると保存される
3. ゲーム中に右クリックを押し続けると、早く設置できる
4. 手に**ブロック**を持っているときだけ動く（食べる・飲む等には触らない）

## テスト

`./gradlew -p ifuto-fastplace testFastplace`（CI で毎回）
