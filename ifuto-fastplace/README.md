# FastPlace + Scaffold + Aim Assist + Auto Tool + ClickCrystal + Auto Stun Slam + Auto Safe Anchor (ifuto-fastplace)

右クリック長押しの連続設置を**人間の連打のクセ**で行う Mod に、
**Web のモックと同じ見た目の Module Select 画面**（RShift）、**God Bridge 用 Scaffold**、
**剣用 Aim Assist**、**Auto Tool**、**ClickCrystal**、**Auto Stun Slam**、
**Auto Safe Anchor** を追加したものです。

- `RShift` … Module Select 画面を開く / 閉じる
- `R` … FastPlace の ON/OFF（操作設定 → `Ifuto FastPlace` で変更できます）

## できること

### FastPlace
- ブロックの連続設置間隔を変更（20〜500ms、既定 55ms）
- 連打中だけ画面右上に CPS を表示（小数1桁・毎 tick 変動・整数にならない）
- 手に**ブロック**を持って右クリックを押しているときだけ動く（食べる・飲む等には触らない）
- 設置は **描画フレーム単位**（tick の 50ms に丸めない）。間隔は ms 単位のまま
  ばらつくので、サーバーから見て「50, 50, 50, 100…」と**同じ数字が並ばない**
- **同じ / ほぼ同じ間隔は続けない**（直近 4 回と ±6ms 以内なら必ずずらす）
- 置くときは `interactBlock` + `swingHand` という**バニラと同じ入口**。
  パケットを自前で作らないので、CPS 表示 Mod にもそのまま数えられる

### Scaffold（God Bridge）
ブロックを持って**前へ歩くだけ**で、足元の続きへ自動でブロックを置きます。

- ジャンプなし・スニークなし
- **プレイヤーの視界は前を向いたまま**。体（＝サーバーに送られる本物の向き）だけが
  ブロックへ向く。パケットの偽装はしていません
- モジュールを **OFF** にした / **ブロックを手放した** / 画面を開いた ときは、
  人間が顔を上げるのと同じ速度プロファイルで、**今見ている方向へ**なめらかに戻ります
- ブロックを持っていないとき・モジュールが OFF のときは発動しません

### Aim Assist（剣・近接）
**左クリック 1 回**で相手を掴み、人間の速度で寄ります（押しっぱなし不要）。

- クリックした瞬間の視線が、相手の当たり判定を **1.2 倍**に広げた箱に当たり、
  **ブロックや他のエンティティで遮られていなければ**掴む（倍率は設定で 1.0–1.6x）
- 掴んだら既定 3 秒追う（再クリックで延長）。距離・視界を外れたら手放す
- **カクつき対策**: 狙い点を毎フレーム作り直し、回転は「誤差を跨がない」ように
  クランプするだけ。以前あった「誤差が悪化したフレームは 0 にする」「安全域を
  外れたら強い補正を足す」という 2 つのルールを外したので、
  **回転量が 0 になるフレームが無い**（速度が連続）
- 目標の近くでは角速度を誤差に比例させる（等速で押し込まない）ので、
  最後はすっと止まる。最低速度を保証しないので**微小な振動（かくかく）が出ない**
- 歩きながら狙うと **進行方向と逆向きに 1.2°** ずれる（設定 −4〜+4°、0 で無効）
- マウス入力は常にそのまま効く（視点を奪わない・パケット偽装なし）

### ClickCrystal（結晶爆破）
黒曜石（岩盤）を**左クリックして押している間だけ**、置く → 殴るを繰り返します。
**離した瞬間に止まります**。

- 対象が黒曜石/岩盤で、上が空気、クリスタルをホットバーに持っているときだけ動く
- **パケットを組み立てません。実際に操作します**:
  1. 黒曜石の上面へ**本当に視点を向ける**（毎フレーム少しずつ）
  2. クロスヘアが本当にその上面に当たっていることを毎フレーム `raycast` で確認してから
     `interactBlock`（バニラの右クリックと同じ入口）で置く
  3. 置いたクリスタルへ**本当に視点を向け**、目視できる・遮蔽が無い・
     3.0 ブロック以内、の 3 つを満たしたときだけ `attackEntity` で殴る
- だから **見えない位置のクリスタルは殴りません**。壁越しも、届かない距離も殴りません
- クリスタルが来なかった / 置けなかった ときは、何もせず次の機会を待つ
- 間隔 (20–300ms)・振り向く速さ・届く距離・終了後に元のスロットへ戻すか、を設定可能

### Auto Stun Slam
**メイスで叩く直前に、斧へ持ち替えて盾を割り、すぐメイスに戻して叩きます。**

発動条件（すべて満たすときだけ）:

- 手にメイス、ホットバーに斧がある
- **落下距離 1 以上で浮遊中**（メイスのスマッシュが乗る高さ）
- **視点の先の相手が盾を構えている**（使用中のアイテムが盾）
- 相手が生きていて、3.4 ブロック以内で、遮蔽が無い

動き: メイスでクリック → 斧へ切り替え → **スロットがサーバーに届いてから**斧で盾を割る →
メイスへ戻す → メイスで叩く。スロット変更も攻撃もバニラと同じ入口なので、
パケットの偽装はありません。メイスで盾を叩いて終わり、にはなりません。

### Auto Safe Anchor
**自分がリスポーンアンカーを置いた瞬間**、手前に 1 ブロック置ける空間があるときだけ、
安全なアンカー運用を自動で行います。

1. グロウストーンを持って、アンカーに **1 回だけ**チャージ
2. アンカーの**手前の地面**へ視点を移し、グロウストーンを 1 ブロック置いて壁を作る
   （アンカーを向いたまま置くと **2 回目のチャージ**になってしまうので、必ず地面を向く）
3. アンカーを持って、壁ごしに見えるアンカーの面へ向き直って右クリック（起爆）

各段階で「いま本当にどこを見ているか」を毎フレームレイキャストで確かめ、
**狙いが合ったときだけ右クリック**します。アンカーが壊れた / 置けなかった /
見えなくなった ときは**起爆せずに**やめます。

### ClickGUI（The Client.）
HTML の理想図に合わせて作り直しました。

- **面取り（45° のカクカク）をやめて角丸 + アンチエイリアス**。
  角は 1px 単位で被覆率を計算して描くので、拡大してもギザギザになりません
- **文字はバニラフォントを等倍・影なし**で描く（拡大による「ドットが目立つ」見た目をやめた）
- 背景は**プレイ画面のまま軽くブラー + 20% だけ暗く**する（真っ黒/青で塗り潰さない）
- 2 カラム（左: カテゴリ / 右: モジュール）。行は「名前 + 説明」の 2 段組み
- **左クリック = ON / OFF**、**右クリック = コンテキストメニュー**
  （設定を開く / ON-OFF / キーバインドを見る）
- ヘッダーをドラッグするとウィンドウが動く。ホバーとトグルはアニメーション付き
- 設定画面も同じ意匠（4 種類のスライダー / トグルはすべて角丸）
- `RShift` で開閉（開いた直後の同じ押下では閉じない）、`ESC` で閉じる

## 人間らしさの根拠（Scaffold）

設置のテンポは**歩く速さ**で決まります（一定 CPS で連打しない）。
その上に、視線と指の統計モデルを重ねています。詳細は
[`docs/ifuto-fastplace-scaffold.md`](../docs/ifuto-fastplace-scaffold.md)。

- **視線**: 大きい移動はサッケードのメインシーケンス（持続時間 `D ≈ 2.7A + 23 ms`、
  ピーク角速度 `PV ≈ 850(1-e^(-A/6)) deg/s`）に合わせた最小ジャーク軌道。
  小さいズレは時定数 ~70ms の追従。常にわずかな振戦とドリフトが乗る
- **設置リズム**: Wing–Kristofferson (1973) の間隔分解 + ex-Gaussian の裾、
  疲労と回復、たまの「ためらい」と「二度打ち」、1/f 的なテンポの揺れ
- **設置位置**: 本物のブリッジと同じく「今乗っているブロックの側面」を叩く

## 人間らしさの根拠（Aim Assist）

詳細は [`docs/ifuto-fastplace-aimassist.md`](../docs/ifuto-fastplace-aimassist.md)。

- **反応時間**: 滑動性追従の立ち上がり潜時 100〜130ms
- **速度の形**: メインシーケンス `PV ≈ 850(1-e^(-A/6)) deg/s` を弱めて上限 220 deg/s
- **なめらかさ**: 速度そのものに慣性（時定数 65ms）を持たせ、目標の 1.6° 以内では
  誤差に比例して減速する。**最低速度を保証しない**ので、狙いが合っているときに
  押し返す振動が出ない
- **振戦・ドリフト**: 生理的振戦 σ ≈ 0.05° + 有界ドリフト ±0.12°。
  **狙う点だけを揺らし、向きには積まない**
- **外さない保証**: 1 フレームの回転は誤差の 92% まで。誤差を跨がないので
  行き過ぎない（回転を捨てるフレームも無い）

## 人間らしさの根拠（Auto Tool）

詳細は [`docs/ifuto-fastplace-autotool.md`](../docs/ifuto-fastplace-autotool.md)。

- **選択肢の数**: `RT = 165 + 62·log2(n+1) ms`（Hick 1952 / Hyman 1953）
- **練習**: `+150·(n+1)^(-0.35) ms`（Newell & Rosenbloom 1981 のべき乗則）
- **証拠の強さ**: 差が明白なほど速い（Ratcliff 1978）
- **反復**: 同じスロットなら ×0.88 / **誤り後**: 直後の判断は +110〜170ms

## 設定

| 場所 | 項目 |
| --- | --- |
| ClickGUI → Scaffold → `…` | ジャンプ抑止 / 視点を前のまま / 人間らしさ / 腕を振る / 設置ペース |
| ClickGUI → FastPlace → `…` | 有効 / CPS 表示 / 設置間隔 |
| ClickGUI → Aim Assist → `…` | クリックで掴む / 掴む時間 / 判定の倍率 / プレイヤーだけ / 強さ / 視野 / 滑らかさ / 進行方向のズレ / 先読み / 押している間だけ |
| ClickGUI → ClickCrystal → `…` | 間隔 / 振り向く速さ / 狙う距離 / 元のスロットに戻す |
| ClickGUI → Auto Stun Slam → `…` | 斧に替えてから / メイスに戻してから / 元のスロットに戻す |
| ClickGUI → Auto Safe Anchor → `…` | 振り向く速さ / 操作どうしの間隔 / 元のスロットに戻す |
| ClickGUI → Auto Tool → `…` | 人間らしさ / 掘っている間だけ / 壊れかけを避ける |
| 操作設定 (Controls) | モジュール画面を開くキー、FastPlace の ON/OFF キー |

設定は `config/ifuto-fastplace.json` に保存されます。

## テスト

```bash
./gradlew -p ifuto-fastplace testFastplace   # 連打タイミングモデル
./gradlew -p ifuto-fastplace testScaffold    # 視線・設置リズム・距離トリガの安全性
./gradlew -p ifuto-fastplace testAim         # 反応時間・速度上限・当たり判定・滑らかさ
./gradlew -p ifuto-fastplace testAutoTool    # 道具選択の判断時間モデル
```

CI では `build` に全部ぶら下げてあるので、壊れたらビルドが落ちます。

## 注意

- ブロック自動設置・連打・エイムアシスト・自動持ち替えが禁止されているサーバーでは
  使わないでください。サーバーのルールと BAN リスクは自己責任で。
- `ifuto-f3` を同時に入れている場合、同じ RShift を取り合わないよう
  f3 側（0.2.1 以降）はモジュール画面と Scaffold を自動で休みます。
